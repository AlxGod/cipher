# Cipher

A rhyme finder and beat player for rappers, for Windows.

- Finds rhymes in the dictionary **and in your own lyrics** (the ones you overuse, and fresh ones you haven't touched)
- Plays YouTube beats while you write, loops any part of a beat, and saves beats as MP3 or WAV
- Reads your lyrics only. It never changes, moves or deletes your files

## Install

1. Go to **[Releases](../../releases/latest)** and download **Cipher-Setup-….exe**.
2. Run it. Windows may say "Windows protected your PC". Click **More info**, then **Run anyway**. (This happens because Cipher isn't from a big company that pays for a security certificate.)
3. Cipher opens and walks you through a one-minute setup.

## Updates

Cipher checks for updates when it opens. When there's a new version you'll see **Update available**. Click **Update now** and it installs and reopens by itself.
